# Domain Docs

This repository uses a single-context layout.

Before exploring domain behavior, read `CONTEXT.md` and relevant ADRs under `docs/adr/` when they exist. Missing files require no warning; proceed with the available code.

Use terminology defined in `CONTEXT.md` consistently. If work contradicts an existing ADR, identify the conflict explicitly instead of silently overriding the decision.

Expected layout:

```text
/
├── CONTEXT.md
├── docs/adr/
└── src/
```
